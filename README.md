# Premier Schools Exhibition Landing Page
# Overview

A modern, fully responsive landing page designed for the Premier Schools Exhibition, helping parents discover and connect with leading schools in a single place.

The project focuses on delivering an engaging user experience through interactive sections, auto-scrolling showcases, responsive layouts, and conversion-driven enquiry forms.
<hr></hr>
#Features

✨ Responsive design for Desktop, Tablet, and Mobile

✨ Interactive Hero Section with school showcase

✨ Enquiry Form for parent registrations

✨ Auto-scrolling School Category Cards

✨ Participating Schools Logo Marquee

✨ Pre-Schedule Appointment Section

✨ Sticky Navigation on Scroll

✨ Smooth Animations & Transitions

✨ Mobile-Friendly Sliders with Pagination Dots

✨ Modern Gradient-Based UI Design
